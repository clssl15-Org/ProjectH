# 범위

진행 중인 대화가 있을 때 `LanguageManager.SetLanguage()`로 언어가 바뀌면, 현재 대화 진행 상황을 유지하면서 표시 언어를 즉시 바꾸는 작업 기록이다.

이번 범위는 대화 재생 흐름과 기존 `LanguageChanged` 구독 UI 중심이다. 유물 정보창처럼 열릴 때 문자열을 생성하는 별도 UI 전수 갱신은 포함하지 않았다.

# 기존 구조

`LanguageManager.SetLanguage()`는 이미 정적 `LanguageChanged` 이벤트를 발행하고 있었다.

캐릭터 이름 텍스트, 일반 UI 텍스트, 월드 레코드 텍스트처럼 일부 UI는 이 이벤트를 구독해 언어 변경 시 다시 표시한다.

반면 대화 재생은 `DialogueManager.Play()` 내부 로컬 변수로 현재 스크립트와 줄 번호를 들고 있었다.

- `DialogueScriptLibrary`는 기존에 제목만으로 대화 스크립트를 찾았다.
- 언어별 대화 에셋은 같은 제목을 공유하므로 제목만 조회하면 첫 번째 등록 에셋이 선택될 수 있었다.
- `DialogueUI.SetContent()`와 `BubbleDialogueUI.Show()`는 호출 순간의 언어로 텍스트를 구성하고, 언어 변경 이벤트를 직접 반영하지 않았다.

# 확인 결과

대화 에셋은 `ko`, `en` 폴더에 각각 22개씩 있고, `_language` 값도 `Korean`, `Engilsh`로 들어가 있었다.

제목 쌍은 맞지만 일부 대화는 언어별 줄 수가 다르다.

- `Stage0_Arrival_First_1`
- `Stage0_Arrival_Reentry`
- `Satge0_Arrival_Reentry_ChangeName_1`
- `Stage1_Arrival_Reentry`
- `Stage2_Arrival_Reentry`
- `Stage3_Arrival_Reentry`

따라서 언어 변경 시 현재 줄 번호를 유지하되, 새 언어 스크립트의 줄 수가 더 짧으면 마지막 줄로 보정하는 방식이 필요했다.

# 적용 내용

## 1. 대화 스크립트 조회에 언어 조건 추가

`DialogueScriptSO`에 `Language` 프로퍼티를 추가하고, `DialogueScriptLibrary.TryGetDialogueScript()`를 제목과 언어를 함께 받는 API로 변경했다.

현재 형태:

```csharp
public bool TryGetDialogueScript(string title, Language language, out DialogueScriptSO script)
```

`DialogueManager.Play()`는 현재 `LanguageManager.Language`를 넘겨 현재 언어의 대화 스크립트를 찾는다.

## 2. 진행 중인 대화 상태를 필드로 승격

`DialogueManager.Play()` 내부 로컬 상태를 필드로 올렸다.

- 현재 대화 제목
- 현재 `DialogueScriptSO`
- 현재 줄 index
- 대화 종료 시 UI 닫기 여부
- 종료 콜백

이 상태를 통해 언어 변경 후에도 현재 줄과 종료 흐름을 유지할 수 있게 했다.

## 3. 언어 변경 시 현재 줄 재렌더링

`DialogueManager`가 `LanguageManager.LanguageChanged`를 구독한다.

진행 중인 대화가 없으면 아무 작업도 하지 않는다.

진행 중인 대화가 있으면 다음 순서로 처리한다.

1. 같은 제목의 새 언어 스크립트를 찾는다.
2. 새 언어 스크립트가 없거나 비어 있으면 `InvalidOperationException`을 던진다.
3. 현재 줄 index를 유지한다.
4. 새 언어의 줄 수가 더 짧으면 마지막 줄로 보정한다.
5. 현재 줄을 새 언어 텍스트로 다시 표시한다.

`ShowOneRandomLine` 대화도 언어 변경 시 새 랜덤 줄을 뽑지 않고 기존 선택 index를 유지하거나 보정한다.

## 4. 타이핑 상태 정책 반영

언어 변경 직전 현재 줄이 완전히 표시된 상태였으면 새 언어 줄도 즉시 완전 표시한다.

언어 변경 직전 타이핑 중이었다면 현재 줄 번호는 유지하되, 새 언어 문장을 처음부터 다시 타이핑한다.

이를 위해 `TMPTypeHandler.TypeDialogue()`, `DialogueUI.SetContent()`, `BubbleDialogueUI.Show()`에 `showImmediately` 선택 인자를 추가했다.

## 5. 말풍선 대화 갱신

말풍선 대화는 언어 변경 시 새 언어 텍스트 기준으로 패널 크기를 다시 계산한다.

캐릭터 위치 추적 함수는 그대로 유지해 같은 대상 위치에 새 언어 말풍선을 표시한다.
