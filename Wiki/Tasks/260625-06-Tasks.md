# [수정 결과] 0625 엔딩 자막 Mask 빌드 위치 불일치

작성일: 2026-06-25

# 범위

`Assets/Scenes/Ending/EndingScene.unity`에서 에디터와 빌드 실행 시 엔딩 자막 위치와 Mask 영역이 다르게 보이는 문제를 확인하고 수정한 기록이다.

이번 작업은 다음 범위만 포함한다.

- 엔딩 씬 CanvasScaler 설정 확인
- 엔딩 자막 Mask와 Text RectTransform 동작 확인
- 빌드 해상도 차이에 따른 UI 좌표 스케일 불일치 수정

엔딩 텍스트 내용, 번역 테이블, 엔딩 후 씬 전환 폴백은 이번 범위에 포함하지 않는다.

---

# 현상

제보된 빌드 화면에서는 자막 시작 위치가 에디터보다 더 아래쪽에 표시되고, Mask 영역 중간에서 자막이 잘려 끝까지 이동하지 않는 것처럼 보였다.

관련 구현:

- `Assets/Scenes/Ending/EndingScene.unity`
- `Assets/Scenes/Ending/EndingVideoController.cs`
- `Assets/Scenes/Ending/EndingTextAssigner.cs`
- `Assets/Scenes/Ending/EndingTextTable.txt`

---

# 원인

`EndingTextAssigner`는 TMP 텍스트 내용만 대입하며 RectTransform이나 Mask 영역은 변경하지 않는다.

실제 위치 차이의 주된 원인은 `EndingScene.unity`의 CanvasScaler가 `Constant Pixel Size`로 설정되어 있었던 것이다.

기존 설정:

```text
m_UiScaleMode: 0
m_ReferenceResolution: {x: 800, y: 600}
```

반면 엔딩 자막 Mask와 Text 이동값은 1920x1080 화면 기준에 가까운 고정 픽셀 좌표로 배치되어 있었다.

- Mask: 아래 기준 고정 위치와 고정 크기
- Text: `EndingVideoController.MoveY()`에서 `-550f`에서 `822f`까지 고정 Y 이동

따라서 빌드 실행 해상도가 에디터 Game View와 달라지면 Canvas 좌표가 화면에 비례해 줄어들지 않고, Mask의 실제 가시 영역이 크게 달라졌다.

예를 들어 기존 설정에서는 1920x1080에서 Mask 세로 가시 영역이 약 544px이지만, 1280x720에서는 약 184px만 남아 자막이 중간에서 잘리는 현상이 발생할 수 있다.

---

# 수정 내용

`Assets/Scenes/Ending/EndingScene.unity`의 CanvasScaler를 16:9 기준 스케일 방식으로 변경했다.

```text
m_UiScaleMode: 1
m_ReferenceResolution: {x: 1920, y: 1080}
m_MatchWidthOrHeight: 0.5
```

이제 엔딩 자막 Mask와 Text 이동 좌표가 화면 해상도에 맞춰 함께 스케일된다.

기대 효과:

- 에디터와 빌드에서 자막 시작 위치 차이가 줄어든다.
- 1280x720 같은 16:9 해상도에서도 Mask 영역이 1080p 기준 비율에 맞게 유지된다.
- 기존 `EndingVideoController`의 자막 이동 시간과 흐름은 그대로 유지된다.
