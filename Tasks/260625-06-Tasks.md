빌드에서 렐릭 습득 이후 동전던지기 재생이 끝난 뒤 진행이 멈춘 사례를 기준으로, `RelicAcquisitionUI`의 동전 결과 완료 경로에 안전장치를 추가한다.

- `Wiki/Tasks/260625-06-Tasks.md`

# 현상

유물 획득 UI에서 동전던지기 연출이 끝난 뒤 결과 화면으로 돌아오지 않고, 게임 진행이 멈춘 사례가 있었다.

`RelicAcquisitionUI`는 열릴 때 `Time.timeScale = 0`으로 게임을 멈추고 `InputHub.Block(this)`로 입력을 막는다. 정상 흐름에서는 동전 연출 완료 뒤 유물 결과 화면과 닫기 버튼을 보여주고, 사용자가 닫으면 `Time.timeScale`과 입력 차단이 복구된다.

따라서 동전 완료 처리가 누락되면 닫기 버튼으로 갈 수 없고, 정지 상태가 유지되어 빌드에서 멈춘 것처럼 보일 수 있다.

---

# 원인 후보

기존 구현은 동전 영상 길이를 기준으로 만든 `Timer` 콜백에서만 후속 처리를 수행했다.

후속 처리 내용:

- `RelicManager.Instance.AddRelic(...)` 호출
- 성공/실패 설명 표시
- 동전 페이지 숨김
- 유물 결과 페이지 표시
- 닫기 버튼 표시

위 콜백이 영상 길이 계산 문제, 영상 재생 오류, 클립 누락, 예외 등으로 실행되지 않거나 중간에서 끊기면 UI가 닫기 가능한 상태까지 도달하지 못한다.

---

# 수정 방향

1. 동전 결과 완료 처리를 별도 메서드로 단일화한다.
2. 완료 플래그를 두어 타이머, 영상 종료 이벤트, 오류 이벤트, 안전 타이머가 중복 호출되어도 유물은 한 번만 추가한다.
3. `VideoPlayer.loopPointReached`와 `VideoPlayer.errorReceived`를 보조 완료 신호로 사용한다.
4. 동전 클립이 없거나 길이가 비정상이면 경고 로그를 남기고 즉시 닫기 가능한 결과 화면으로 복구한다.
5. 예상 재생 시간에 짧은 여유 시간을 더한 안전 타이머를 두어 완료 신호 누락 시에도 결과 화면으로 복구한다.
6. 예외가 발생해도 `finally`에서 결과 페이지와 닫기 버튼을 반드시 표시한다.
